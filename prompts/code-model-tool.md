Recommend an execution path (`recommend`), switch the SAME conversation to its configured coding model and effort (`start`), restore the original model and effort for review (`finish`), or inspect settings and the current turn's routing receipt (`status`). Automatic routing supports `off`, `observe` and `enforce`. An active automatic gate supplies its receipt in the system context; reuse its effective route and use `status` for details. A new material choice or changed evidence can justify another `recommend` call. With automatic routing off, call `recommend` with a concise task summary before choosing the executor. Set `allowSubagent` only with explicit user authorisation. TypeSafe receives the task summary and sanitised model and quota facts; configured fallback handles credential or request failures. Receipts record backend, confidence, quota, timing and fallback reason. A recommendation selecting a coding phase requires `start` as a standalone call with the recommended `effort`; an automatic receipt whose action is `entered_code_model` confirms the phase is already active. Omitting effort uses the saved profile. Complete code and targeted checks in the same conversation, then call `finish` alone for original-model review. Existing permissions and provider safety approvals continue to apply.
